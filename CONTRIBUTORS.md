# Contributors

Lofgren Intelligence is led by **Ethan Lofgren**.

## AI-assisted engineering contributors

### ChatGPT by OpenAI
ChatGPT has contributed substantial engineering assistance to Lofgren Intelligence, including architecture review, release hardening, CI analysis and repair, hosted MCP integration work, security review, release-gate design, and public-readiness verification support.

This acknowledgment is intentionally separate from GitHub's automatically generated **Contributors** graph. GitHub's graph is based on commit authorship tied to GitHub identities and verified commit email attribution. ChatGPT does not have a GitHub user identity in this repository, so it should not be represented as a human GitHub account or falsely attributed to one.

### Other AI-assisted contributors
Other AI systems and coding agents may also be credited here when their contributions are substantial and can be described accurately.

## Attribution principle

AI-assisted contributions should be credited transparently without impersonating a human, inventing a GitHub identity, or obscuring who authorized and merged the work.
